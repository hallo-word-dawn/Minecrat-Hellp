## 下载启动器
Minecrat需要启动器，推荐使用PCL（Plain Craft Launcher）启动器[龙腾猫跃（即PCL作者）爱发电主页](https://afdian.com/a/LTCat)
点击本教程上面的链接后，我们就能进入龙腾猫跃的爱发电主页，然后发现另一个链接，不过在跳转此链接之前，我们要在爱发电主页中记住一个信息，即提取码。我们可以看到，提取码就是[pcl2]
如果你成功跳转应该会发现有三个下载入口分别为下载地址1，下载地址2，备用下载（提取码pcl2），分别对应三个下载网盘（夸克，迅雷，蓝奏云）我更推荐点最后一个，因为蓝奏云支持在不登录的情况下进行下载，有助于更好的*~~白嫖~~*获取软件
下载成功后，打开压缩包，就能找
